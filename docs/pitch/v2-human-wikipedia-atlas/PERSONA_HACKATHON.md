# Persona And Focus Hackathon

## Goal
Stress-test Tymio's story, buyer, and first demo before locking the roadmap too early.

## What We Are Testing
### Story options
1. Human Wikipedia for every project
2. Living project atlas
3. Ask Tymio anything about your project
4. AI-native project office

### Buyer options
1. Founder
2. CTO / tech lead
3. PM / delivery owner
4. OSS maintainer

### Demo options
1. Ask-anything project Q and A
2. AI agent with better project context
3. Live status without meetings
4. AI-managed project operations below the initiative layer

## Core Doctrine To Hold Constant
These are not under test during the hackathon:

- Initiative = human-owned why
- AI handles the operational layers below the initiative
- Tymio truth lives in the product
- Docs and agent briefs are generated dynamically
- Integrations are first-class project context

## Hackathon Format
Run short focused sessions around each persona.

For each session:
1. Present one headline
2. Present one 60-second product explanation
3. Show one key demo flow
4. Ask the same set of questions
5. Score clarity, excitement, credibility, and urgency

## Suggested Test Matrix
| Persona | Headline | Demo | What to watch |
|---|---|---|---|
| Founder | Human Wikipedia | Ask-anything Q and A | Emotional resonance, "I need this now" |
| CTO / tech lead | Living project atlas | Agent + human shared context | Trust, technical credibility |
| PM / delivery owner | AI-native project office | Live status / risks / dependencies | Relief from status overhead |
| OSS maintainer | Ask Tymio anything | Contributor onboarding / project memory | Clarity for new contributors |

## Common Questions To Ask
- What do you think Tymio is after 30 seconds?
- What problem do you think it solves?
- Which part feels new versus existing tools?
- Which claim feels strongest?
- Which claim feels exaggerated or vague?
- Would you try this? Why or why not?
- What would you expect the first usable version to do?
- Have you tried Obsidian, Notion, or Confluence for project knowledge? What happened when people stopped maintaining it?

## Scoring Template
Use a simple 1-5 score for each:

- Clarity
- Emotional pull
- Credibility
- Urgency
- Demo strength
- Buyer fit

Add one free-text field:

- "What phrase would you repeat to someone else?"

## Desired Outcomes
By the end of the hackathon, decide:

1. Primary public story
2. Primary first buyer
3. Primary Phase 1 demo
4. Primary landing page headline
5. Which assumptions stay open versus become roadmap inputs
